# Visita virtual — exportación web

Este repositorio contiene **solo** la exportación web (Godot 4.7.2, Compatibility/WebGL 2).
El proyecto fuente no se publica aquí.

Estado actual: **portada + panorámica 360° fotorrealista + visita virtual v7** (complejo ADCLEN, 8 apartamentos y piscina). Texturas y modelos CC0 (ambientCG, Poly Haven); visor 360° con three.js (MIT).
